# SSCO Vocab Type

English fill-in-the-blank typing practice (67 questions, including OP295A).

**iPhone:** open [https://chinghei520-art.github.io/ssco-vocab-type/](https://chinghei520-art.github.io/ssco-vocab-type/) in Safari, tap **Share**, then **Add to Home Screen**. Open the icon from the home screen.

**Later updates:** replace `vocab.js` and `vocab.json`, then push to `main`. Pages serves the new bank. Leave `index.html` unless the app itself changes.
