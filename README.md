# SSCO Vocab Type

English fill-in-the-blank typing practice (55 questions, including OP295A).

**iPhone:** open [https://chinghei520-art.github.io/ssco-vocab-type/](https://chinghei520-art.github.io/ssco-vocab-type/) in Safari, tap **Share**, then **Add to Home Screen**. Open the icon from the home screen.

**Later updates:** replace `vocab.js` and `vocab.json`, then push to `main`. Pages serves the new bank. Leave `index.html` unless the app itself changes.

**Practice history sync (optional):** the same Google account can merge attempt history across browsers. Until `firebase-config.js` is filled in, records stay on this device only. Setup and the clear / sign-out rules: [docs/SYNC_SETUP.md](docs/SYNC_SETUP.md).
